# README visuals

The [project README](../../README.md) opens with the linked pixel-font wordmark,
a one-line description and one hero screenshot. Feature sections are text-only;
keep the body left-aligned and use the screenshot for the visual overview.

`hero-placeholder.svg` reserves that position until a current screenshot is
available. Replace it with `hero.png` or `hero.webp`, update the image path and
alt text in the project README, and remove the placeholder.

For the hero capture:

- Use a wide composition, preferably 16:9, with one readable main node and
  connected text, media and interactive nodes around it.
- Show enough of the canvas to make the relationships clear without zooming
  out so far that all text becomes unreadable at GitHub's content width.
- Keep the app in focus, without desktop panels, browser chrome or open menus
  obscuring the project.
- Use non-sensitive example content. Hide provider keys, account details and
  private source material.

The previous screenshots and per-feature placeholders have been removed from
this directory. Original promotional captures outside the repository are unchanged.

`open-app.svg` is the linked **scatter.study** wordmark, not a screenshot
placeholder. It also serves as the page heading, so do not add a second plain
“Scatter” heading above it. The entire “scatter.study” uses Press Start 2P
outlines, with no background, border or icons. Keep its destination and visible
domain consistent with the app URL.

The setup, privacy and license information stays visible. Production-build,
test and credential-check instructions use GitHub's native expandable sections.
Do not add decorative badges, per-feature images or custom page CSS.
